# Bedrock frontend integration

Install `frolaxhq/bedrock-frontend` to add Inertia sharing, frontend artifact validation,
navigation, `frontend:install`, `ui:override`, and `module:make --frontend`. The separate
`@frolax/bedrock` npm package supplies React/UI and Vite+ authoring tools. Node is needed
for builds, not for serving previously built modules. Existing public PHP names and npm
exports remain unchanged.
